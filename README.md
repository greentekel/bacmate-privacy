# Politica de confidențialitate BacMate

Ultima actualizare: 15 septembrie 2026

BacMate este construit local-first: înveți fără cont, fără reclame și fără tracking. Datele de progres rămân pe dispozitiv și pot fi resetate din setările aplicației.

## Ce date colectăm

Aplicația poate salva local profilul de matematică BAC, progresul, notițele, favoritele, setările și ora reminderului zilnic.

## Date transmise

BacMate nu trimite progresul tău către servere BacMate și nu include un backend de conturi. Formulele și simbolurile sunt incluse în aplicație, se afișează offline și nu necesită un serviciu extern.

## Notificări

Reminder-ele sunt notificări locale programate pe dispozitiv. Le poți activa sau opri oricând din aplicație.

## Ștergere date

Poți șterge progresul sau poți face reset complet din Setări. Reset complet elimină profilul, progresul, preferințele și onboarding-ul local. Fiind date păstrate doar pe dispozitiv, dezinstalarea aplicației le șterge la rândul ei.
